# 동적 표 연동 명세 — 배송 시작 안내 (SHIP_START)

- 언어: ko, en, ja (기준 ko)
- 번들 스키마: `tx-mail-bundle` v1 (상세: docs/bundle-schema.md)

## 공통 규칙

1. 발송 HTML 의 동적 표 `<tbody>` 에는 표식 치환자 `|!#-rows_<표id>|` 하나만 들어 있습니다.
2. 표식 교체와 행 생성은 **메일 처리 워커 담당**입니다. 워커는 표식을 **`<tr>…</tr>` 연속 문자열**(행마다 행 템플릿을 채운 것)로 교체합니다. 행 템플릿 열 수는 언어 공통입니다.
3. 행 템플릿의 `{{var}}` 는 행 데이터 값으로 치환합니다. 변수 이름은 아래 표의 `vars` 목록을 따릅니다.
4. **확정:** 서버는 `rows_` 접두 치환자(`|!#-rows_<표id>|`)를 지우거나 오류로 처리하지 않고 **그대로 통과**시킵니다.
5. 참고(권장): 서버가 본문 전체의 `|!#-x|` 치환을 먼저 하고, 그 뒤에 표식 `|!#-rows_<id>|` 를 행 문자열로 교체하면 행 값에 `|!#-` 가 있어도 재치환되지 않습니다. 워커 내부 구현(치환 규칙 세부·순서)은 워커 담당 부서가 정합니다.
6. 워커의 `{{ }}` 치환 세부 규칙(없는 변수 처리 등)은 워커 담당 영역이며 이 문서 범위 밖입니다.

## 표 `orders`

- 삽입 표식: `|!#-rows_orders|`
- 열 수: 2

### 변수

| 변수 | 설명 | 샘플 |
|---|---|---|
| `{{name}}` | 상품명 | 무선 이어폰 |
| `{{qty}}` | 수량 | 2 |

### 언어별 행 템플릿

**ko**

```html
<tr style="height: 20px;"><td style="padding: 4px;">{{name}}</td><td style="padding: 4px;">{{qty}}개</td></tr>
```

**en**

```html
<tr style="height: 20px;"><td style="padding: 4px;">{{name}}</td><td style="padding: 4px;">{{qty}} pcs</td></tr>
```

**ja**

```html
<tr style="height: 20px;"><td style="padding: 4px;">{{name}}</td><td style="padding: 4px;">{{qty}}個</td></tr>
```

### 예시 행 데이터

```json
[
  {
    "name": "무선 이어폰",
    "qty": "2"
  },
  {
    "name": "케이블 <3m> & \"세트\"",
    "qty": "1"
  }
]
```

### 렌더 결과 예시 (표식 자리에 들어갈 문자열)

언어 `ko`, 예시 행 2개(앱 참조 렌더 출력):

```html
<tr style="height: 20px;"><td style="padding: 4px;">무선 이어폰</td><td style="padding: 4px;">2개</td></tr><tr style="height: 20px;"><td style="padding: 4px;">케이블 &lt;3m&gt; &amp; &quot;세트&quot;</td><td style="padding: 4px;">1개</td></tr>
```

> 예시 렌더의 `&lt;` `&amp;` 등은 앱 미리보기가 샘플 값을 안전하게 보여주기 위한 표시일 뿐이며, 이 규약은 값 이스케이프를 요구하지 않는다(워커 담당 영역).

### 행 수 상한 (Gmail 102KB 기준)

Gmail 은 본문이 104448B(102KB)를 넘으면 잘라 숨깁니다. 상한 = floor((104448 − 본문 바이트) ÷ 행당 바이트). 다른 동적 표의 행은 0 으로 가정, 행당 바이트는 예시 행 값으로 추정(실제 값 길이에 따라 달라짐).

| 언어 | 본문(표식 포함) B | 행당 B(추정) | 최대 행 수 |
|---|---|---|---|
| ko | 639 | 113 | 918 |
| en | 614 | 114 | 910 |
| ja | 638 | 113 | 918 |
