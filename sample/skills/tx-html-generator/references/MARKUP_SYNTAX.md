## 변수 시스템

### 기본 개념

변수는 외부 시스템(예: 메일링 시스템)에서 실제 값으로 치환되는 플레이스홀더입니다.

### 표준 형식

**올바른 형식**: `|!#-변수명|`

```
안녕하세요, |!#-cust_nm|님!

주문번호: |!#-order_no|
배송예정일: |!#-delivery_date|
```

### 자동 변환

사용자가 `{변수명}` 형식을 사용하면 자동으로 표준 형식으로 변환됩니다:

```
입력: 안녕하세요, {고객명}님!
변환: 안녕하세요, |!#-고객명|님!
```

### 주의사항

- 변수명에는 영문, 숫자, 언더스코어(`_`)만 사용합니다
- 변수명은 대소문자를 구분합니다
- 변수가 실제로 존재하는지 확인할 수 없으므로, 명명은 사용자와 협의합니다

### 일반적인 변수 예시

```
|!#-cust_nm|          # 고객명
|!#-cust_email|       # 고객 이메일
|!#-account_id|       # 계정 ID
|!#-order_no|         # 주문번호
|!#-tracking_no|      # 운송장번호
|!#-date|             # 날짜
|!#-company_nm|       # 회사명
|!#-amount|           # 금액
```

## 테이블

### 가로형 테이블 (Horizontal Table)

칼럼 헤더가 상단 행에 배치되는 일반적인 테이블 형식입니다.

**기본 구조**:
```
[표: 가로형]
{헤더1| 헤더2| 헤더3}
- 행1값1| 행1값2| 행1값3
- 행2값1| 행2값2| 행2값3
[/표]
```

**렌더링 결과**:
| 헤더1 | 헤더2 | 헤더3 |
|-------|-------|-------|
| 행1값1 | 행1값2 | 행1값3 |
| 행2값1 | 행2값2 | 행2값3 |

**예시**:
```
[표: 가로형]
{항목명| 수량| 단가| 금액}
- 노트북| 2| 1500000| 3000000
- 마우스| 5| 30000| 150000
- 키보드| 3| 80000| 240000
[/표]
```

### 세로형 테이블 (Vertical Table)

각 행마다 헤더가 좌측에 배치되는 키-값 쌍 형식입니다.

**기본 구조** (콜론 권장):
```
[표: 세로형]
- 헤더1: 값1
- 헤더2: 값2
- 헤더3: 값3
[/표]
```

**파이프 구분자** (값에 콜론 포함 시):
```
[표: 세로형]
- 헤더1| 값1
- 헤더2| 값2
- 헤더3| 값3
[/표]
```

**렌더링 결과**:
| 헤더1 | 값1 |
| 헤더2 | 값2 |
| 헤더3 | 값3 |

**예시 (콜론 - 직관적)**:
```
[표: 세로형]
- 고객명: 홍길동
- 이메일: hong@example.com
- 연락처: 010-1234-5678
- 배송지: 서울시 강남구, 테헤란로 123
[/표]
```

**예시 (파이프 - 시간 표기 등 콜론 중복 시)**:
```
[표: 세로형]
- 배송시간| 14:30:00
- 접속 URL| https://example.com:8080
[/표]
```

### 구분자 선택 가이드

**콜론(`:`)을 사용하세요**:
- 일반적인 키-값 쌍 표현 (가독성 최고)
- 값에 콜론이 없는 대부분의 경우

**파이프(`|`)를 사용하세요**:
- 값에 시간 표기 포함 시 (예: `14:30:00`)
- 값에 URL 포함 시 (예: `https://example.com`)
- 가로형 테이블과 일관성 유지 필요 시

**콤마가 포함된 값도 직접 사용 가능**:
```
[표: 가로형]
{이름| 주소| 비고}
- 홍길동| 서울시 강남구, 테헤란로 123| 없음
- 김철수| 부산시 해운대구, 센텀로 456| 배송 시 연락 필수
[/표]
```

**변수가 포함된 경우**:
```
[표: 세로형]
- 주문자| |!#-cust_nm|
- 배송주소| |!#-addr1|, |!#-addr2|
- 연락처| |!#-phone|
[/표]
```

### 목록에서 표로 자동 변환

**중요 규칙**: `- 항목: 값` 형식의 목록은 자동으로 세로형 표로 변환합니다.

**변환 전 (일반 목록)**:
```
주문 정보:
- 주문번호: ORD-2024-001
- 주문일자: 2024-01-15
- 결제금액: 150,000원
- 결제수단: 신용카드
```

**변환 후 (세로형 표)**:
```
주문 정보:

[표: 세로형]
- 주문번호: ORD-2024-001
- 주문일자: 2024-01-15
- 결제금액: 150,000원
- 결제수단: 신용카드
[/표]
```

**예외**: 일반적인 설명 목록은 변환하지 않습니다:
```
서비스 특징:
- 빠른 배송: 24시간 내 출고
- 안전한 포장: 이중 완충재 사용
- 실시간 추적: 모바일 앱으로 확인

↓ (변환하지 않음 - 설명형 목록이므로)
```

## 콜아웃

콜아웃은 중요한 정보를 시각적으로 강조하는 박스 형태의 컴포넌트입니다.

### 정보 콜아웃 (Info)

일반적인 안내 정보를 표시합니다. 파란색 테마로 렌더링됩니다.

**구조**:
```
[정보: 제목]
내용을 작성합니다.
여러 줄 작성 가능합니다.
[/정보]
```

**예시**:
```
[정보: 배송 안내]
주문하신 상품은 영업일 기준 2-3일 내 배송됩니다.
제주도 및 도서산간 지역은 추가 배송일이 소요될 수 있습니다.
[/정보]
```

### 경고 콜아웃 (Warning)

주의가 필요한 정보를 표시합니다. 빨간색 테마로 렌더링됩니다.

**구조**:
```
[경고: 제목]
주의가 필요한 내용을 작성합니다.
[/경고]
```

**예시**:
```
[경고: 서비스 중단 안내]
시스템 점검으로 2024-01-20 02:00-04:00 동안 서비스가 중단됩니다.
점검 시간 중에는 모든 기능을 이용하실 수 없습니다.
[/경고]
```

### 강조 콜아웃 (Accent)

일반적인 강조 정보를 표시합니다. 노란색 테마로 렌더링됩니다.

**구조**:
```
[강조: 제목]
강조할 내용을 작성합니다.
[/강조]
```

**예시**:
```
[강조: 특별 혜택]
이번 달 신규 가입 고객에게는 첫 배송비가 무료입니다!
[/강조]
```

### 콜아웃 내 마크다운

콜아웃 내부에서 표준 마크다운 문법을 사용할 수 있습니다:

```
[정보: 참고사항]
**중요**: 다음 항목을 확인하세요.

1. 배송지 주소 정확성
2. 연락처 입력 여부
3. 결제 정보 확인

자세한 내용은 [고객센터](https://example.com)를 참조하세요.
[/정보]
```

### 콜아웃 내 테이블

콜아웃 내부에 테이블을 포함할 수 있습니다:

```
[경고: 점검 일정]
다음 시간 동안 서비스가 중단됩니다.

[표: 가로형]
{일자| 시간| 내용}
- 2024-01-20| 02:00-04:00| 서버 업그레이드
- 2024-01-22| 01:00-02:00| 데이터베이스 최적화
[/표]
[/경고]
```

## 버튼

버튼은 사용자가 클릭할 수 있는 CTA(Call-to-Action) 요소입니다.

### 기본 구조

**형식**: `[버튼, 레이블, URL, 스타일]`

- **레이블**: 버튼에 표시될 텍스트
- **URL**: 클릭 시 이동할 주소 (필수, 없으면 `#`)
- **스타일**: 버튼 외관 (선택, 생략 시 자동 결정)

### 스타일 종류

#### 1. Primary (주요 액션)

파란색 배경, 가장 중요한 액션에 사용합니다.

```
[버튼, 지금 신청하기, https://apply.example.com, primary]
[버튼, 주문 확인, https://order.example.com, primary]
```

**자동 선택 키워드**: 신청, 등록, 확인, 구매, 결제, 시작

#### 2. Secondary (부가 액션)

하늘색 배경, 부차적인 액션에 사용합니다.

```
[버튼, 자세히 보기, https://info.example.com, secondary]
[버튼, 문의하기, https://contact.example.com, secondary]
```

**자동 선택 키워드**: 보기, 문의, 안내, 확인(부가적)

#### 3. Warn (경고 액션)

빨간색 배경, 주의가 필요한 액션에 사용합니다.

```
[버튼, 주문 취소, https://cancel.example.com, warn]
[버튼, 삭제하기, https://delete.example.com, warn]
```

**자동 선택 키워드**: 취소, 삭제, 중단, 거부

#### 4. Outline (선택적 액션)

투명 배경에 테두리만, 선택적인 액션에 사용합니다.

```
[버튼, 나중에 하기, #, outline]
[버튼, 둘러보기, https://browse.example.com, outline]
```

**자동 선택 키워드**: 나중에, 건너뛰기, 선택

### 스타일 자동 결정

스타일이 생략된 경우 레이블 텍스트를 분석하여 자동으로 결정합니다:

```
[버튼, 배송 추적하기, https://tracking.example.com]
→ "추적"이라는 키워드로 primary 자동 선택

[버튼, 고객센터 문의, https://support.example.com]
→ "문의"라는 키워드로 secondary 자동 선택

[버튼, 구독 해지, https://unsubscribe.example.com]
→ "해지"라는 키워드로 warn 자동 선택
```

### 버튼 배치

**단일 버튼**:
```
[버튼, 주문 확인하기, https://order.example.com, primary]
```

**다중 버튼** (가로 배치):
```
[버튼, 주문 확인, https://order.example.com, primary]
[버튼, 주문 취소, https://cancel.example.com, warn]
```

렌더링 시 같은 문단에 있는 연속된 버튼들은 자동으로 가로 정렬됩니다.

### URL 처리

**절대 URL**:
```
[버튼, 홈페이지, https://www.example.com, primary]
```

**상대 URL**:
```
[버튼, 내 주문, /my-orders, primary]
```

**빈 URL** (임시 또는 JavaScript 처리):
```
[버튼, 준비중, #, outline]
```

### 버튼과 변수

버튼의 URL에 변수를 포함할 수 있습니다:

```
[버튼, 내 주문 확인, https://example.com/orders/|!#-order_no|, primary]
[버튼, 배송 추적, https://tracking.example.com?no=|!#-tracking_no|, secondary]
```

## 표준 마크다운

TracX Logis 마크업은 표준 마크다운 문법을 모두 지원합니다.

### 제목

```
# 제목 1 (h1)
## 제목 2 (h2)
### 제목 3 (h3)
```

### 텍스트 강조

```
**굵게** 또는 __굵게__
*기울임* 또는 _기울임_
~~취소선~~
```

### 링크

```
[링크 텍스트](https://example.com)
[링크 텍스트](https://example.com "툴팁 텍스트")
```

### 목록

**순서 없는 목록**:
```
- 항목 1
- 항목 2
  - 하위 항목 2-1
  - 하위 항목 2-2
- 항목 3
```

**순서 있는 목록**:
```
1. 첫 번째
2. 두 번째
3. 세 번째
```

### 인용문

```
> 인용문 내용입니다.
> 여러 줄로 작성할 수 있습니다.
```

### 수평선

```
---
```

## 엣지 케이스 처리

### 1. 중첩된 구조

**콜아웃 내 테이블**:
```
[정보: 배송 정보]
다음과 같이 배송됩니다.

[표: 세로형]
- 배송업체| CJ대한통운
- 운송장번호| |!#-tracking_no|
[/표]
[/정보]
```

**콜아웃 내 버튼**:
```
[경고: 결제 확인 필요]
결제가 완료되지 않았습니다. 24시간 내 결제를 완료해주세요.

[버튼, 지금 결제하기, https://payment.example.com, primary]
[/경고]
```

### 2. 특수 문자 처리

**HTML 특수 문자**:
- `<`, `>`, `&` 등은 자동으로 이스케이프됩니다
- 예: `3 < 5` → `3 &lt; 5`

**마크다운 특수 문자**:
- `*`, `_`, `#` 등을 그대로 표시하려면 백슬래시(`\`)를 사용합니다
- 예: `\*이것은 기울임이 아닙니다\*`

### 3. 빈 값 처리

**테이블**:
```
[표: 가로형]
{이름, 이메일, 전화}
- 홍길동, hong@example.com, 
- 김철수, , 010-1234-5678
[/표]
```
빈 값은 빈 셀로 렌더링됩니다.

**변수**:
```
배송지: |!#-addr|
```
변수가 치환되지 않으면 그대로 표시됩니다.

### 4. 긴 텍스트

테이블 셀이나 버튼 레이블에 긴 텍스트가 있을 경우:
- 테이블: 자동 줄바꿈
- 버튼: 텍스트 길이에 맞게 너비 조정

### 5. 잘못된 문법

**닫는 태그 누락**:
```
[정보: 제목]
내용
(닫는 태그 없음)
```
→ 오류 메시지 출력 및 해당 부분 건너뛰기

**잘못된 테이블 구조**:
```
[표: 가로형]
{헤더1, 헤더2}
- 값1, 값2, 값3
[/표]
```
→ 칼럼 수 불일치 경고 및 최선의 렌더링 시도

## 완전한 예시

### 배송 안내 이메일

```
# 배송이 시작되었습니다

안녕하세요, |!#-cust_nm|님!

주문하신 상품의 배송이 시작되었습니다.

[표: 세로형]
- 주문번호| |!#-order_no|
- 운송장번호| |!#-tracking_no|
- 배송업체| CJ대한통운
- 예상 도착일| |!#-est_delivery_date|
[/표]

[정보: 배송 추적]
실시간으로 배송 현황을 확인하실 수 있습니다.
```
