# TracX Logis 마크업(TXMD) 문법 상세 명세

`.txmd` = **머리말(front matter) + 한국어 원문 + 번역 줄(`@en`/`@ja`)** 로 된 텍스트 파일 하나. 앱('프로젝트 > .txmd 불러오기')이 읽어 다국어(ko/en/ja) 프로젝트를 만든다.
번역 줄이 없는 파일은 기존 단일 언어 마크업과 100% 같다. 문법의 기준 구현은 앱 파서(`src/markup/parser.ts`)이고 이 스킬의 파서(`scripts/tx_markdown_parser.py`)가 같은 출력을 낸다.
완성 예시는 `example.md`(검증을 통과한 것만 실려 있다).

## 1. 파일 구조와 머리말

```
---
kind: mail
name: 배송 시작 안내
templateCode: SHIP_START
subject.ko: 배송이 시작되었습니다
subject.en: Your shipment is on its way
subject.ja: 発送を開始しました
---
# 본문 마크업이 여기부터 시작
@en Your shipment is on its way
@ja 発送を開始しました
```

- 파일 **맨 첫 줄**이 `---` 이면 다음 `---` 줄까지가 머리말이다. 한 줄에 `key: value`(**첫 `:`** 뒤를 trim, 따옴표 불필요, 값 안의 `:` 는 그대로). 빈 줄·`#` 로 시작하는 줄은 무시한다. 줄 끝 주석(`# …`)은 없다(값의 일부가 된다).
- 닫는 `---` 가 없으면 머리말이 없는 것으로 읽는다(경고). 머리말 없이 본문만 있어도 된다 — 대신 앱에서 이름·제목을 직접 입력해야 한다.

| 키 | 필수 | 설명 |
|---|---|---|
| `kind` | 선택 | `mail`(기본) 또는 `notice`. 그 외 값은 경고 후 mail |
| `name` | 권장 | 프로젝트 이름 |
| `templateCode` | 선택 | 백오피스 템플릿 코드(메일) |
| `subject.ko` `subject.en` `subject.ja` | 권장 | 메일 제목 / 공지 제목. **언어는 ko·en·ja 만**(다른 언어는 무시). 본문 `# h1` 과 별개다 |

- **메일(`mail`)**: 로고 헤더·푸터·600px 표 래퍼(셸)는 앱이 붙인다 — 본문에는 쓰지 않는다. 제목(`subject.*`)과 본문에 치환자 `|!#-x|` 를 쓸 수 있고, 동적 표를 쓸 수 있다.
- **공지(`notice`)**: 셸 없는 본문 조각. **치환자 `|!#-x|`·`{x}`·`{{x}}`·동적 표 금지**(검증 오류). 제목은 `subject.*` 로만 준다.
- 본문 첫 부분의 `[헤더]` 마커는 쓰지 않는다(셸은 앱이 붙인다).

## 2. 번역 줄 (`@en` / `@ja`)

```
@<언어코드> <번역 텍스트>
```

- 줄 맨 앞(들여쓰기 허용)의 `@en`·`@ja` 뒤에 공백, 이어서 번역. **`en`, `ja` 만** 번역 줄로 인식한다. 그 외(`@fr`, `@jp`, `@example.com 으로…`)는 일반 텍스트가 되어 본문에 그대로 찍힌다(`@jp` 같은 오타는 검증이 경고한다).
- 번역 텍스트에도 `**굵게**`, `[링크](url)`, `|!#-변수|` 를 쓴다.
- **번역 줄은 번역할 블록 바로 아래, 빈 줄 없이** 붙인다. 빈 줄 뒤나 구분선 뒤의 `@` 줄은 대상이 없어 경고 후 무시된다.
- 같은 언어의 `@` 줄이 여러 개면 원문 줄 수만큼 `<br/>`(인용은 `<br>`)로 이어진다. 원문이 여러 줄이면 번역도 같은 줄 수로 쓴다.
- 번역 줄이 없는 블록은 그 언어에서 비어 있다(미번역 — 검증이 경고).

### 블록별 번역 줄 위치

| 블록 | 번역 줄 위치 |
|---|---|
| 제목 `# …`(h1~h3) | 제목 줄 바로 아래 |
| 문단 | 문단 안, 원문 줄들 뒤(빈 줄 앞) |
| 인용 `> …` | 인용 줄들 바로 뒤. `> @en …` 도 허용 |
| 목록 항목 | **그 항목 바로 아래**(중첩 항목도 각자). 부모 항목의 번역은 자식 항목보다 먼저 둔다. 들여쓰기는 자유 |
| 가로형 표 헤더 | `{…}` 줄 바로 아래 `@en {A| B}` (중괄호 생략 가능). 칸 수가 같아야 한다 |
| 가로형 표 행 | 행(`- …`) 바로 아래 `@en - a| b` (`-` 생략 가능). 셀 단위 |
| 세로형 표 행 | 행 바로 아래 `@en - 헤더: 값` (`-` 생략 가능). 구분자 규칙(5절)은 언어마다 달라도 됨 |
| 콜아웃 제목 | 여는 줄 `[정보: 제목]` 바로 아래 (제목이 없는 콜아웃이면 경고 후 무시) |
| 콜아웃 본문 블록 | 최상위와 같은 위치 규칙(문단·목록·표·버튼·인용 각각) |
| 버튼 | 버튼 줄 바로 아래 `@en 레이블` (레이블만. URL·스타일은 언어 공통). 연속 버튼 그룹에서도 각 버튼 아래 |
| 구분선 `---` | 없음 |

## 3. 변수(치환자)

외부 시스템(메일 발송 서버)이 실제 값으로 바꾸는 자리표시자.

- 표준 형식 `|!#-변수명|`. 사용자가 `{변수명}` 으로 써도 `|!#-변수명|` 으로 자동 변환된다(본문의 일반 `{중괄호}` 도 변환되니 중괄호를 글자로 쓰지 말 것).
- 변수명에 쓸 수 있는 문자: 영문·숫자·`_`·`.`·`-`·한글. 대소문자 구분. 실제로 존재하는 변수인지는 확인할 수 없으므로 이름은 사용자와 정한다(예: `cust_nm` 고객명, `order_no` 주문번호, `tracking_no` 운송장번호).
- 버튼·링크 URL 안에도 쓸 수 있다: `https://t.com/?no=|!#-tracking_no|`.
- **번역에서도 같은 변수를 그대로** 쓴다(이름 변경·번역 금지). 어순 때문에 위치는 달라져도 된다. 언어 간 변수 집합이 다르면 검증 오류.
- 공지에는 쓸 수 없다. 동적 표의 행 변수 `{{x}}` 는 별개 체계(5-3절)이며 본문 변수와 이름이 겹치면 안 된다.
- 단일 열 가로형 표 헤더 `{이름}` 은 변수 변환에 걸려 깨진다 — 열이 1개인 표는 세로형으로 쓴다.

## 4. 인라인 서식·링크

| 문법 | 결과 |
|---|---|
| `**굵게**`, `__굵게__` | `<strong>` |
| `*기울임*`, `_기울임_` | `<em>` (`_` 는 단어 경계에서만 — `snake_case_word` 는 그대로) |
| `***굵은 기울임***` | `<strong><em>` |
| `~~취소선~~` | `<del>` |
| `[텍스트](https://…)` | `<a href>` |

- 취소선 인식 조건: 안쪽 양끝이 공백·`~` 가 아니어야 한다(`a ~~ b ~~ c`, `~~~x~~~` 는 그대로). 단일 `~`(`월~금`)·닫히지 않은 `~~` 는 일반 텍스트. 다른 서식과 중첩 가능(`~~**굵게**~~`).
- 변수·`{{행 변수}}`·링크 URL·본문 속 맨 URL(`https://…` 공백까지) 안의 `_ * ~` 는 서식으로 해석하지 않는다.
- HTML 태그는 이스케이프되어 글자 그대로 보인다(`3 < 5` → `3 &lt; 5`). 원시 HTML·이미지·백슬래시 이스케이프(`\*`)·링크 툴팁(`"title"`)은 지원하지 않는다.
- **링크는 항상 새 창**: `[x](url)`·맨 URL·버튼은 `target` 을 쓰지 않아도 `target="_blank" rel="noopener noreferrer"` 로 나온다(`mailto:`·`tel:`·`sms:`·`#앵커` 제외). 작성자가 신경 쓸 필요는 없다.
- 맨 URL 보호는 공백·`< > [ ] )` 에서 끝난다. 괄호가 든 URL 은 `[텍스트](url)` 로 쓴다.

## 5. 표

### 5-1. 가로형 (열 머리글이 위)

```
[표: 가로형]
{항목명| 수량| 금액}
@en {Item| Qty| Amount}
- 노트북| 2| 3,000,000
@en - Laptop| 2| 3,000,000
- 마우스| 5| 150,000
@en - Mouse| 5| 150,000
[/표]
```

- 헤더 줄 `{a| b| c}` 와 데이터 행 `- a| b| c` 는 **파이프(`|`)** 로 칸을 나눈다. **콤마 구분이 아니다**(`{이름, 이메일}` 은 칸 하나가 된다).
- 칸 수가 헤더와 다르면 경고 후 자동 보정(부족하면 빈 칸, 넘치면 버림). 빈 칸은 `- 홍길동| hong@a.com| ` 처럼 비워 둔다.
- 번역 행의 칸 수도 헤더와 같아야 한다(다르면 경고 후 보정).

### 5-2. 세로형 (행마다 머리글이 왼쪽)

```
[표: 세로형]
- 주문번호: |!#-order_no|
@en - Order No.: |!#-order_no|
- 배송시간| 14:30:00
@en - Delivery time| 14:30:00
[/표]
```

- 한 행 = `- 헤더: 값` 또는 `- 헤더| 값`. **줄에서 먼저 나오는 구분자**를 쓴다(파이프가 콜론보다 먼저면 파이프). 값에 `:`(시각·URL)가 들어가면 **파이프**를 쓴다.
- 값에 콤마는 그냥 써도 된다(`- 배송지| 서울시 강남구, 테헤란로 123`).
- 번역 줄(`@en - 헤더: 값`)의 구분자는 원문과 달라도 된다.

### 목록 → 세로형 표 (작성 규칙)

`- 항목: 값` 꼴의 **정보 나열**(주문번호·일자·금액 등)은 목록 대신 세로형 표로 쓴다. 설명형 목록(`- 빠른 배송: 24시간 내 출고` 같은 특징 나열)은 목록 그대로 둔다.

### 5-3. 동적 표 (메일 전용 — 서버가 tbody 행을 만든다)

```
[표: 가로형, 동적: orders]
{상품명| 수량| 금액}
@en {Item| Qty| Amount}
- {{name}}| {{qty}}개| {{amount}}원
@en - {{name}}| {{qty}} pcs| {{amount}} KRW
@var name 상품명
@var qty 수량
@sample name=무선 이어폰| qty=2| amount=90,000
@sample name=보조배터리| qty=1| amount=32,000
[/표]
```

- 여는 줄에 `, 동적: <표id>`(영문·숫자·`_`·`-`). **가로형만**. 세로형·콜아웃 안·공지에서는 쓸 수 없다(경고/오류).
- 데이터 행(`- …`)은 **행 템플릿 1개**만 쓴다(2개 이상이면 경고, 첫 행만). 행 변수는 `{{name}}`.
- 행 템플릿의 고정 문구(`개`, `pcs`)는 번역 대상이다. 번역 행에도 같은 `{{변수}}` 를 모두 쓴다.
- `@var <이름> <설명>`: 변수 설명(선택). `@sample k=v| k=v`: 예시 행(여러 줄 = 여러 행). 이 두 줄은 동적 표 안에서만 의미가 있고 언어 코드와 무관하게 항상 인식한다.
- 미리보기 HTML 은 `@sample` 행으로 tbody 를 채운다(값은 이스케이프). 발송용에서는 `<tbody>|!#-rows_<표id>|</tbody>` 표식 하나만 남고 서버가 행을 채운다 — 이 표식을 본문에 직접 쓰지 말 것. `@sample` 이 없으면 미리보기에도 표식만 보인다(경고).
- 행 변수 `{{x}}` 이름은 본문 치환자 `|!#-x|` 와 달라야 한다.

## 6. 콜아웃

```
[정보: 제목]            [경고: 제목]            [강조: 제목]
내용                    내용                    내용
[/정보]                 [/경고]                 [/강조]
```

- 종류 → 클래스: 정보 `callout-info`(파랑), 경고 `callout-warn`(주황), 강조 `callout-accent`(청록). 제목은 생략 가능(`[정보]`). 출력은 `div.callout.callout-* > h3 + 본문`.
- **본문에는 최상위와 같은 블록 문법**을 쓴다.

| 본문 요소 | 문법 |
|---|---|
| 문단 | 연속 줄(`<br/>` 로 이어짐), 빈 줄로 문단 분리 |
| 소제목 | `### 소제목`(h3) |
| 목록 | `- x` / `1. x`, 들여쓰기로 중첩 |
| 표 | `[표: 가로형]…[/표]`, `[표: 세로형]…[/표]` |
| 버튼 | `[버튼, 레이블, URL, 스타일]` (연속하면 그룹) |
| 인용 | `> x` |
| 구분선 | `---` |

- 표·버튼은 앞뒤에 빈 줄을 두는 것을 권장(필수는 아님). 문단은 목록·표·버튼·인용·`#`·구분선·콜아웃 시작 줄에서 빈 줄 없이도 끝난다.
- **금지/주의**
  - 콜아웃 안에 콜아웃은 못 쓴다 — 인용(`<blockquote>`)으로 낮아지고 경고.
  - 본문 안의 `#`·`##` 줄은 **콜아웃을 끝낸다**(경고). 소제목은 `###` 만.
  - 같은 종류를 중첩할 수 없다. 닫는 `[/종류]` 필수(없으면 파일 끝/다음 `#`·`##` 까지가 본문이 되고 오류로 보고).
  - 콜아웃 안 표의 `[/표]` 도 반드시 닫는다.
  - 콜아웃 안 동적 표는 불가(경고 후 정적 표).
  - 내용이 빈 콜아웃은 경고.
- 번역: 여는 줄 바로 아래의 `@en`/`@ja` 줄 = **제목** 번역. 이후는 본문 블록마다 바로 아래에(2절 표).

## 7. 버튼

```
[버튼, 레이블, URL, 스타일]
[버튼, 레이블, URL]            ← 스타일 자동 결정
@en Label                       ← 번역은 레이블만
```

- 레이블 필수, URL 생략 시 `#`. 콤마가 든 레이블·URL 은 큰따옴표로 감싼다: `[버튼, "주문, 결제", https://x.com]`.
- 스타일: `primary`(파란 면, 주요), `secondary`(흰 바탕 파란 글자·테두리), `warn`(취소·삭제 류), `outline`(선택적). 생략하면 **한국어 레이블**에서 자동 결정 — primary: 신청·등록·확인·구매·결제·시작·추적·완료 / warn: 취소·삭제·중단·거부·해지·차단 / outline: 나중에·건너뛰기·선택 / 그 외 secondary. 스타일은 언어 공통이므로 의도가 중요하면 **명시**한다.
- 빈 줄 없이 이어진 버튼 줄은 한 그룹(`<p class="btn-group">`)으로 가로 배치. 단일 버튼은 `<p><a class="btn btn-…">`.
- URL 에 변수 가능(`https://t.com/?no=|!#-tracking_no|`). URL 은 번역하지 않는다(언어 공통).

## 8. 표준 마크다운 블록

```
# 제목 1 (h1)
## 제목 2 (h2)
### 제목 3 (h3)

- 항목 1
- 항목 2
  - 하위 항목 2-1
1. 첫 번째
2. 두 번째

> 인용문
> 여러 줄

---
```

- 제목은 h1~h3 만. 목록은 `-`/`*`(순서 없음), `1.`(순서 있음), 들여쓰기로 중첩(순서 목록 중첩도 가능).
- 인용 여러 줄은 `<br>` 로 이어져 `<blockquote><p>` 한 개가 된다. 구분선은 `---`/`***`/`___`.

## 9. 엣지 케이스·제한

- 한 문단 = 빈 줄까지의 연속 줄(`<br/>` 로 이어짐). 번역 줄도 이 문단 안에 둔다.
- 표 안의 빈 줄은 무시된다. 번역 줄은 대상 행 바로 아래에 둔다.
- 닫는 태그 누락: 콜아웃·표는 파일 끝(또는 다음 `#`·`##`)까지를 본문으로 보고 경고한다. 검증은 이를 **오류**로 올린다.
- `[/정보]` 같은 짝 없는 닫는 태그는 일반 문단으로 남는다(검증이 `leftover-markup` 경고).
- 원본(단일 언어) 파서와의 의도적 차이: 변수·URL 안의 `_` 오인 수정, 중첩 순서 목록 무한루프 수정, 레이블 첫 글자 손실 수정(`[버튼,레이블]`), 서식 레이블 단일 버튼도 `<p>` 로 감쌈, `{{x}}` 는 변수 변환 제외.
- 새 문법(콜아웃 본문 확장·취소선·번역 줄·동적 표·머리말)은 앱 파서와 출력이 같도록 대조 테스트(`tests/test_parity.py`)로 보증한다.

## 10. 검증 규칙

`python3 tx_generate.py in.txmd` 가 보고하는 항목. **오류**가 있으면 종료 코드 1(파일을 전달하지 말고 고친다), **경고**는 의도한 것인지 확인한다.

| 코드 | 수준 | 의미 |
|---|---|---|
| `unclosed` | 오류 | 콜아웃·표의 닫는 태그 누락/제목에서 자동 종료 |
| `placeholder-mismatch` | 오류 | 번역의 치환자 집합이 ko 와 다름 |
| `subject-placeholder-mismatch` | 오류 | 제목 치환자 집합이 언어 간 다름 |
| `notice-placeholder` | 오류 | 공지에 `|!#-x|`·`{x}`·`{{x}}`(본문·제목) |
| `notice-dynamic-table` | 오류 | 공지에 동적 표 |
| `dynamic-table-unsupported` | 오류 | 세로형·콜아웃 안에 동적 표 |
| `dynamic-table`, `row-var-collides` | 오류 | 행 템플릿 변수 누락/중복 id/본문 치환자와 이름 충돌 |
| `untranslated` | 경고 | 번역 줄이 없는 블록(언어별 목록) |
| `lang-missing` | 경고 | 한 언어의 번역이 전혀 없음 |
| `placeholder-moved` | 경고 | 집합은 같지만 블록별 치환자가 다름(어순 이동 등) |
| `link-changed` | 경고 | 번역에서 링크 URL 이 원문과 다름 |
| `subject-missing`, `name-missing`, `no-front-matter`, `front-matter` | 경고 | 머리말 누락/형식 |
| `unknown-lang-code` | 경고 | `@jp` 등 지원하지 않는 번역 줄 코드 |
| `leftover-markup`, `raw-html` | 경고 | 해석되지 못한 마크업/원시 HTML |
| `orphan-translation`, `column-mismatch`, `no-sample`, `parse` | 경고 | 대상 없는 번역 줄/칸 수/@sample 없음/기타 파서 경고 |
